# Navch Android App – QA Portfolio

## Project Overview

This project demonstrates manual QA testing of the Navch Android application, an online shopping application where users can browse products, manage shopping carts, add delivery addresses, and use checkout features.

The goal of this project was to practice real-world QA activities, identify application issues, and document testing results professionally.

## Application Under Test

- **Application:** Navch Android App
- **Platform:** Android
- **Testing Environment:** Android Studio Emulator
- **Computer OS:** Windows 11
- **Testing Type:** Manual Functional Testing

## Testing Objectives

- Verify the main application features.
- Check user authentication and registration.
- Test product selection and shopping cart functionality.
- Verify address management and checkout.
- Test payment method selection.
- Check user profile functionality.
- Identify functional and usability issues.

## Testing Approach

The project used manual and exploratory testing.

Testing activities included:

- Reviewing application functionality.
- Creating test scenarios.
- Designing detailed test cases.
- Executing test cases.
- Identifying and documenting defects.
- Summarizing testing results.

## Testing Results

A total of 20 test cases were documented and evaluated.

| Result | Total | Percentage |
|---|---:|---:|
| Passed | 5 | 25% |
| Failed | 15 | 75% |
| Not Executed | 0 | 0% |
| **Total** | **20** | **100%** |

**Defects Identified:** 10

The main issues identified during testing included:

- Inconsistent authentication behavior.
- Shopping cart data not being saved consistently.
- Application crash when entering special characters in the phone number field.
- Product and address form layout problems in landscape mode.
- Unresponsive payment options.
- Incorrect checkout navigation.
- Profile information not being retained after restarting the app.

**Additional Improvement Suggestion:** Add an option to delete saved addresses.
